   - Problem: Når en spiller mistet forbindelsen, krasjet spillet

        posisjon.

        tilbake til playerobjektet uansett socket-id.
     f) updateAll() sender fortsatt tilstand til alle connected
        spillere; disconnected spillere hoppes over.
   - Resultat: Spillet krasjer IKKE lenger ved midlertidig
     forbindelsestab. Spillere kan gå inn og ut uten at

3.1 SYSTEMOVERSIKT
-------------------
Hybrid Poker er et lokalnettverkspoker-spill som støtter både
Texas Hold'em og Omaha. Spillet kjører på en Node.js server
som håndterer all spill-logikk og kommuniserer med klienter
via Socket.IO (WebSocket).

3.2 SPILLEFLYT
--------------
FASEDIAGRAM:
  VENTING ──[set_game_mode + start_new_hand]──► PREFLOP
                                                  │
          ┌────────────────────────────────────────┤
          │                                        ▼
       PREFLOP ◄────[next_phase / start_new_hand]── FLOP → TURN → RIVER → SHOWDOWN
          ▲
          │
          └────[next_phase / start_new_hand]── FINISHED (alle kastet seg)

  VENTING er kun ved serverstart eller når gameMode settes til null.
  Når spillet er igang, går det: PREFLOP → ... → SHOWDOWN/FINISHED → PREFLOP.

VENTING:
- Venting på at en spilletype velges (Texas eller Omaha)
- Spillere kan joine/forlate fritt
- Ingen kort delt ut

PREFLOP:
- Dealerknappen har flyttet til neste spiller
- Blinds assignert (Lilleblind, Storeblind)
- 2 kort (Texas) eller 4 kort (Omaha) delt pr. spiller
- Spillere kan kaste seg
- Når alle aktive spillere har "handlet" → FLOP

FLOP:
- 3 community cards på board
- Kasting muliggjort
- Neste → TURN

TURN:
- 1 community card lagt til
- Kasting muliggjort
- Neste → RIVER

RIVER:
- 1 community card lagt til (totalt 5 på board)
- Kasting muliggjort
- Neste → SHOWDOWN

SHOWDOWN:
- Alle aktive spilleres kort evalueres
- Vinner(e) bestemt via pokersolver
- Vinnerkort vises på hovedskjerm (kun ved showdown)
- Finneshendelse: "Alle andre kastet seg" (foldedWin)

FINISHED:
- Runde avsluttet
- Neste runde: "Neste hånd" → PREFLOP (ny runde)

3.3 SPILLERIDENTITET OG DISCONNECT-HÅNDTERING
-----------------------------------------------
Spiller-objekt:
{
  id: string,          // socket.id (kan endres ved reconnect)
  name: string,        // spillernavn (unikt, case-insensitive)
  seat: number,        // bordposisjon (1-indexed)
  cards: string[],     // private kort, f.eks. ["As", "Kd"]
  folded: boolean,     // har kastet denne runden?
  role: string,        // 'Dealer' | 'Lilleblind' | 'Storeblind' | ''
  connected: boolean   // er WebSocket opptatt?
}

Disconnection Flow:
1. Socket disconnect → connected = false, timeout satt (60s)
2. Dagens spill fortsetter - andre ser at spilleren er offline
3. Hvis spiller reconnecter innen 60s:
   a. Enkelt join_game (navn-based) → rebind socket
   b. rejoin_game (UUID-based) → rebind socket
   c. Timeout klareres, connected = true
4. Hvis 60s utløper uten reconnect:
   - Spiller slettes fra players[]
   - UUID mapping ryddet
   - State broadcast til alle

UUID-mekanisme:
- localStorage: "poker_uuid" → random UUID per browser
- Ved rejoin_game: sender UUID til server
- Server: uuidToPlayerId.get(uuid) → fant player
- Player rebindes til ny socket.id
- uuidToPlayerId.set(uuid, newSocketId)

3.4 HANDEVALUERING
-------------------
TEXAS HOLD'EM:
- Spiller: 2 kort
- Board: 5 kort (ved showdown)
- Evaluering: Alle 7 kort, pokersolver velger beste 5
- API: Hand.solve([card1, card2, board1..5])

OMAHA:
- Spiller: 4 kort
- Board: 5 kort
- Regelen: MUST USE EXAKT 2 av 4 kort + 3 av board
- Evaluering: C(4,2)=6 player-kombos × C(5,3)=10 board-kombos = 60 hands
- API: For hver kombinasjon: Hand.solve([p1,p2,b1,b2,b3])
- Beste kombinasjon vinner

Pokersolver format:
- "As" = Ace of Spades
- "Td" = Ten of Diamonds
- "9h" = Nine of Hearts
- "2c" = Two of Clubs

3.5 BLIND-ROTAASJON
--------------------
- dealerIndex: 0-indexed posisjon i player-array
- Flyttes +1 for hver nye hånd (modulo antall spillere)
- 2 spillere: pos 0 = Lilleblind, pos 1 = Storeblind
- 3+ spillere: pos 0 = Dealer, pos 1 = Lilleblind, pos 2 = Storeblind
- Stokking: Ved valg av ny game mode stokkes hele orderen
  (randomizePlayerSeats) - alle får ny seat-nummer

3.6 EVENT-API (Socket.IO)
--------------------------
CLIENT → SERVER:
  join_game(name)         → Joine spill som 'name'
  set_game_mode(mode)     → 'TEXAS' | 'OMAHA' | null
  start_new_hand()        → Start neste hånd
  next_phase()            → Avansér til neste fase
  player_fold()           → Kast kortene dine
  rejoin_game({uuid})     → Gjeninnlogge med UUID

SERVER → CLIENT (broadcast):
  state_update {
    gameMode, phase, board, winnerInfo,
    players: [{name, seat, role, folded, connected, cards}]
  }

SERVER → CLIENT (per spiller):
  player_state {
    phase, cards, role, folded, winnerInfo
  }

SERVER → CLIENT (ein gang):
  joined {uuid, name}     → Bekreftet rejoin
